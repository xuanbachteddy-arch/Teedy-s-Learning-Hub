# 🦉 Teedy's Hub

**Teedy's Hub** is an all-in-one, highly customizable productivity and study dashboard built entirely with **vanilla HTML, CSS, and JavaScript**. Designed with a playful Duolingo-inspired UI, it combines everything a student needs into a single, seamless web app—no backend required.

👉 **[Live Demo](https://teedylearnhub.netlify.app))**

---

## ✨ Features

### 🎨 UI & Customization
*   **Duolingo-Inspired Design:** Rounded corners, bold colors, and satisfying 3D button clicks.
*   **Fully Bilingual:** Complete support for **English** and **Vietnamese** (🇻🇳/🇬🇧), easily toggled from the sidebar.
*   **Dark Mode:** A beautiful, eye-friendly dark theme.
*   **Custom Accent Colors:** Change the app's primary color (Green, Blue, Purple, Orange) in Settings.
*   **Avatar & Profile:** Choose from multiple avatars and customize your display name.

### 🧠 Study & Learning Tools
*   **🤖 AI Socratic Tutor:** Integrated with the OpenAI API. It doesn't just give you the answer; it guides you step-by-step using the Socratic method (requires an API key).
*   **🗂️ Flashcards:** Create, flip, and delete custom flashcards for active recall.
*   **🧪 Formula Sheet:** A customizable reference sheet grouped by categories (Math, Physics, etc.).
*   **🧮 Draggable Casio Calculator:** A fully functional, scientific calculator modeled after a real Casio, featuring memory functions, trig, and a draggable UI.
*   **🔗 Quick Links:** Save your favorite educational websites for instant access.

### 🍅 Productivity & Tracking
*   **Pomodoro Timer:** Fully customizable work/short break/long break times with a visual progress ring and background notifications.
*   **Time Tools:** Includes a live clock, millisecond Stopwatch, Countdown timer, and Alarm. Integrates with **Windows 11 / OS Web Notifications**.
*   **Habit Tracker:** A visual 7-day grid to build and track daily habits.
*   **Goal Tracker:** Set goals and update your progress with interactive sliders.
*   **Task Management:** Todo list, Task Archive (completed tasks), and Reading List.
*   **Music Integration:** Save and play your favorite Spotify playlists directly from the dashboard.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (No frameworks, no build tools).
*   **Storage:** Browser `LocalStorage` (Your data stays on your device).
*   **APIs:** OpenAI API, Spotify Embed API, Web Notification API.
